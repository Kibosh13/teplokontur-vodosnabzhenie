# Теплоконтур

Статический сайт компании по монтажу отопления и водоснабжения.

## Структура

- `site/` — исходные HTML, CSS, JavaScript и изображения сайта;
- `scripts/prepare-pages.mjs` — подготовка безопасной демонстрации для GitHub Pages;
- `gh-pages` — публикуемая ветка, созданная из `site/`.

Проект не требует сервера, базы данных или локальной сборки. Для просмотра исходной версии достаточно открыть `site/index.html` через любой статический HTTP-сервер.

## GitHub Pages

Скрипт публикации адаптирует абсолютные ссылки под адрес репозитория, добавляет `noindex`, закрывает обход в `robots.txt` и помечает формы как демонстрационные. Данные из форм никуда не отправляются.

```bash
node scripts/prepare-pages.mjs .pages
```
